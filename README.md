# 🎮 GEMINI QUIZ ARCADE (geminiquiz-games)

ブラウザのマイク機能（Web Speech API）やWeb Audio APIを活用した、**音声入力＆早押し対応のクイズゲームコレクション**です。  
外部サーバーの立ち上げ不要で、ブラウザでHTMLファイルを開くだけ（またはGitHub Pages）ですぐにプレイできます。

---

## 🌟 収録ゲーム一覧

| ゲーム名 | ファイル | 概要 / 特徴 |
|---|---|---|
| **総合ポータル** | [`index.html`](index.html) | 全ゲームを一覧から選んで起動できるアーケード風ランチャー画面 |
| **アーケード音声早押しクイズ** | [`voice_answer_quiz.html`](voice_answer_quiz.html) | 『みんはや風』『漢字でGO!風』『QMA風』の3大スキン切替＆音声回答に対応した本格早押しクイズ |
| **GEO地名でGO! 完全統合版** | [`geo_go.html`](geo_go.html) | 世界の道路標識や現地文字（タイ・キリル・ギリシャ・東欧・アラビア・ハングル等）の読み撃破道場 |
| **タイ県名ショートシアター** | [`thai_short_player.html`](thai_short_player.html) | スマホ縦型（9:16）動画風UI＆ずんだもん風合成音声ナレーションで学ぶタイ県名講座 |

## 🚀 遊び方

### 1. ローカルで遊ぶ場合
1. このリポジトリをダウンロード（または `git clone`）します。
2. フォルダ内の **`index.html`** を Google Chrome などのブラウザでダブルクリックして開きます。
3. 遊びたいゲームをクリックしてスタート！

### 2. GitHub Pages でオンライン公開する場合
1. リポジトリの **Settings** > **Pages** を開きます。
2. Build and deployment の Source を **Deploy from a branch** に設定します。
3. Branch を `main` / `root` に設定して **Save** します。
4. 数分で発行されるURLにアクセスすれば、スマホやPCからそのままオンラインで遊べます！

## 🎯 各ゲームの詳細

### 1. 🎤 アーケード音声早押しクイズ (`voice_answer_quiz.html`)
- **3大ビジュアルスキン切替**：
  - **CYBER ARENA（みんはや風）**：ネオンサイバー＆競技クイズ風
  - **DOJO BATTLE（漢字でGO!風）**：和風・集中線・極太明朝体バトル
  - **MAGIC ACADEMY（QMA風）**：魔法陣・アカデミックな装飾
- **回答方法**：
  - 早押しボタンを押してマイクに向かって声で回答（「姫路城！」「バンコク！」等）
  - キーボード入力（テキスト入力）にも完全対応
- **収録カテゴリ**：
  - 🏛️ 世界遺産クイズ（世界遺産検定2級対応）
  - 🌍 世界の地理・国当てクイズ
  - 💡 一般教養・大人の雑学クイズ
  - ✨ 海外地名・世界の文字クイズ（タイ・キリル・アラビア等）
  - 🤖 Gemini AIカスタムクイズ生成モード

### 2. 🗺️ GEO地名でGO! 完全統合版 (`geo_go.html`)
- GeoGuessrや海外旅行で役立つ現地文字・標識の読み取りトレーニング。
- **全6コース収録**：
  - 🇹🇭 **タイ文字・主要15都市＆キロポスト完全制覇**
  - 🇷🇺 **キリル文字・幹線都市コース**
  - 🇬🇷 **ギリシャ＆東欧特殊文字コース**
  - 🇦🇪 **アジア＆アラビア文字コース**
  - 🌐 **キリル・ギリシャ・東欧・ハングル厳選コース**
  - 🔥 **全文字種・総合実践サバイバル（ランダム10問）**
- **機能**：音声回答、キーボード入力、4択アシスト、単語パーツ分解解説、文字早見表（チートシート）付き。

### 3. 🎬 タイ県名 ショートシアター (`thai_short_player.html`)
- TikTokやYouTube Shortsのような縦型9:16スタイルでタイの主要県名の読み方を学習。
- Web Speech Synthesis（音声合成）による音声解説付き。
- タイ語の構成パーツ（クルン＝都、ナコーン＝大都市、ブリー＝町など）の解説。

## 🛠️ 推奨動作環境
- **推奨ブラウザ**：Google Chrome / Microsoft Edge（PC・Android・iOS）
- **マイク権限**：音声回答機能を利用する場合は、ブラウザからのマイク使用許可を「許可」にしてください。
  - ※静かな場所やマイク非対応環境でも、キーボード入力や選択肢アシストで遊べます。
