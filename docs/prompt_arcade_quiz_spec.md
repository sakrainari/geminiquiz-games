# 依頼：アーケード風・音声回答＆早押しクイズWebアプリ（単一HTML完結型）の作成

ブラウザ上で動作する、音声認識（Web Speech API）と早押しシステムを組み合わせた本格的なクイズWebアプリを、**1つのHTMLファイル（HTML / CSS / JavaScript統合、Tailwind CSS利用）**として作成してください。
省略やプレースホルダーは一切使わず、そのまま保存してブラウザで開けば完全に動作する完成品のコードを出力してください。

---

## 1. ビジュアル＆3大アーケードテーマ切替機能
ヘッダーの切替ボタンおよびホーム画面から、プレイ中でもリアルタイムに以下の3つのビジュアルスキン（CSS変数と専用エフェクト）を切り替えられるようにしてください。

1. **『みんはや（みんなで早押しクイズ）』風（CYBER ARENA / デフォルト）**
   - 斜めにカット（`clip-path`）されたシャープな競技クイズボード風の出題ウィンドウ、ネオンシアン＆レッドの配色、立体的な赤い3D早押しボタン。
2. **『漢字でGO!』風（DOJO BATTLE）**
   - 背後に広がる放射状の集中線エフェクト、迫力ある極太明朝体フォント、黒・深紅・金の重厚な和風バトル枠組み、体力ゲージ風のタイマーバー。
3. **『QMA（クイズマジックアカデミー）』風（MAGIC ACADEMY）**
   - 背後にゆっくり回転するSVG魔法陣、金色の装飾フレーム、紫とゴールドの幻想的な配色、クリスタルオーブ型の早押しボタン。

### アーケード演出エフェクト
- **早押しカットイン**：早押しボタンを押した瞬間に画面を斜めに横切る「PUSH!! 回答権獲得！」のレーザー帯カットイン演出。
- **特大判定スタンプ**：正解時は「正解!! (CLEAR!)」、不正解・時間切れ時は「不正解... (MISS)」の特大スタンプが画面中央にバシッと跳ねて表示されるオーバーレイ演出。
- **危機演出（クライシスビネット）**：回答受付タイマーが残り2.5秒を切ると、画面外周が赤く脈打ち、カウントダウン警告音が鳴る演出。

## 2. 早押しクイズシステム（Buzzer Quiz）＆通常モード
ホーム画面で「早押しモード」と「全文出題モード」を切り替え可能にしてください。

- **1文字ずつのプログレッシブ出題**：
  - 早押しモードでは音声読み上げと連動して問題文が1文字ずつ表示され、「読まれた文字数 / 全文字数（%）」「経過秒数」をリアルタイム表示する。
- **早押しボタン＆スラッシュ（`/`）記録**：
  - 画面中央の3D早押しボタン（または `Space` / `Enter` キー）を押した瞬間に音声読み上げを即座に中断し、問題文のどこで押したかを赤い **`/`（スラッシュ）** として問題文中に挿入・記録する。
  - 早く押して正解するほど「早押しスピードボーナス点」が加算されるスコア計算（100点＋最大50点ボーナス）を実装する。
- **回答受付カウントダウンタイマー（発話検知のスマート延長付き）**：
  - 早押しボタンを押すと即座にマイク（音声認識）が自動起動し、回答受付タイマー（5.0秒 / 8.0秒 / 12.0秒から選択可能）が0.1秒単位でカウントダウンを開始する。
  - **重要**：プレイヤーが発話中（`SpeechRecognition` の `interimResults` 取得中）は、残り時間が2.2秒以下にならないようタイマーをホールドし、喋っている途中で理不尽に時間切れになるのを防ぐこと。

## 3. 音声認識・読み上げ・柔軟な表記揺れ正誤判定エンジン
- **音声認識（Web Speech API）＆ハイブリッド入力**：
  - リアルタイムで認識中の文字列（中間結果）を表示し、正解候補に一致した瞬間に確定を待たず即座に「正解！」と判定してテンポよく進行させる。
  - マイクが使えない環境や誤認識時のために、テキスト入力欄と「パス（ギブアップ）」ボタンも常時併設する。
- **表記揺れ吸収ロジック（JavaScript関数）**：
  - カタカナ・ひらがな統一、全角・半角英数統一、記号や空白の除去。
  - 「答えは〜です」「〜だと思います」「えーっと〜かな」といった話し言葉のフィラー（接頭辞・接尾辞）を正規表現で自動除去。
  - 各問題が持つ `acceptedAnswers`（漢字、ひらがな、カタカナ、英語表記、略称などの別解リスト）と照合し、完全一致・部分一致を柔軟に判定する。
- **Web Audio API シンセサイザー効果音**：
  - 外部音声ファイルを使わず、`AudioContext` のオシレーター合成で「出題音（ジャジャン！）」「早押し音（ピコーン！）」「正解音（ピンポン！）」「不正解音（ブブー！）」「残り時間警告音（ピッ・ピッ）」「結果ファンファーレ」を鳴らす。

## 4. PCでの別作業・「ながらプレイ」対応（バックグラウンド＆小窓対策）
PCで別ウィンドウや別タブを開いて作業しながらでもクイズが止まらないよう、以下の機能を実装してください。

1. **Web Worker タイマー**：
   - ブラウザのバックグラウンドタブで `setInterval` が強制間引き（スロットリング）されるのを防ぐため、`Blob` を使ったインライン Web Worker で文字送りタイマーと回答カウントダウンタイマーを駆動させる。
2. **最前面ミニワイプ機能（Document Picture-in-Picture API / フローティング小窓対応）**：
   - ヘッダーに「ミニ窓化（PiP）」ボタンを設置し、対応ブラウザ（Chrome/Edge等）では `documentPictureInPicture` を使って常に画面の隅に最前面表示できるミニクイズウィンドウを開けるようにする（フォアグラウンド扱いになるためマイク認識も途切れない）。
3. **オート進行モード（ハンズフリー連続出題）**：
   - ONにすると、解説の読み上げ終了後、ボタン操作なしで自動的に3秒後に次の問題へ進むトグルスイッチを設ける。

## 5. 初期内蔵クイズパック＆Gemini AI問題生成・振り返り機能
- **内蔵クイズパック（各8問・詳細な解説と豊富な `acceptedAnswers` 付き）**：
  1. **世界遺産クイズ（2級レベル対応）**（姫路城、モン・サン・ミシェル、マチュ・ピチュ、サグラダ・ファミリア、イエローストーン、アンコール、厳島神社、ガラパゴス諸島など）
  2. **世界の地理・国当てクイズ**（ボリビア、スイス、ナイル川、オーストラリア、カナダ、バチカン、アイスランド、ブラジルなど）
  3. **一般教養・雑学クイズ**
- **Gemini AI リアルタイム問題生成機能**：
  - 好きなテーマとGemini APIキーを入力すると、Gemini API（JSONスキーマ指定）を呼び出し、問題文・正解・音声認識用の別解リスト（ひらがな/カタカナ/漢字/略称）・解説を5問自動生成して即プレイできる機能。
- **リザルト＆復習機能**：
  - スコア、ランク（S/A/B/C）、平均解答時間、各問題でどこで早押ししたか（`/`位置付き）の履歴一覧と、「間違えた問題だけ復習する」ボタンを実装する。
