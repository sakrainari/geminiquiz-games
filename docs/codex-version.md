# Codex版・音声早押しクイズ

## 今回の範囲

独立した `codex/` ページに、アーケード音声早押しクイズを実装する。既存の4カテゴリ100問を使用。地名道場・シアター・AI問題生成は今回の対象に含めない。

## 遊ぶ流れ

1. カテゴリ（4種類または混合）、出題数、早押し／全文表示、回答時間を選ぶ。
2. 早押しでは文字送りを見てボタンを押す。全文が出ても早押し前の回答時間は減らない。
3. 回答はマイクまたは文字入力。早押し後のマイク自動起動を標準でONにし、ブラウザの許可後、その問題の回答中は連続認識する。無音による切断は遅延を挟んで再接続する。権限拒否や反復するネットワーク障害は再接続を止め、理由と文字回答を案内する。
4. 正誤、正解、解説を確認して次へ進む。音声認識の誤判定は自己申告として記録できるが、自動採点の正解数・得点と混同しない。
5. 結果画面で各問題と早押し位置を振り返り、間違えた問題だけ復習できる。

## 遊びやすさ

- 読み上げ・効果音・自動マイクを独立して切り替える。
- 回答時間は8秒・12秒・20秒・制限なし。音声イベントを受けたときは残り2.2秒を確保し、延長の合計は最大6秒。時間切れ後の発話で時計を復活させない。
- 音声の未確定文字列は表示のみ。確定した発話が不一致なら回答を終了せず、そのまま言い直せる。古い問題の音声イベントは次の問題へ持ち越さない。
- 一時停止では回答時計・文字送りを止める。タブを離れた場合も一時停止し、戻ってから自分で再開する。
- 早押しはSpace、解説から次へはEnter。文字入力や日本語IME変換中はショートカットを横取りしない。
- 各カテゴリと混合の出題履歴は独立。ページ内では未出題を優先する。
- 苦手問題のIDのみ端末へ保存。保存不可でもゲームは継続できる。保存データはスキーマと既知IDを検査する。
- 外部CDN・APIキー・ビルドを必要としない。見た目はアーケードらしい立体ボタンとスコア表示を使い、問題文と解説の読みやすさを優先する。

## 検証

### 音声入力の切り分け

`microphone.html` はゲームの採点や時間制限から独立した確認画面。`getUserMedia` とWeb Audioで端末内の入力音量を計測し、SpeechRecognitionの認識開始・音声入力開始・発話・文字受信を別に表示する。音量テストでは録音・保存・送信をしない。停止・タブ非表示・画面離脱・非同期の許可待ち終了時にマイクとAudioContextを解放する。実機からの「聞き取り中だが文字が出ない」という報告の根本原因は、入力音量と認識イベントが得られるまで未確定とする。

状態遷移、二重回答防止、早押し得点、タイムアウト、一時停止、自己申告、問題選択、壊れた保存データをNodeで検査する。ブラウザで開始→早押し→文字回答→解説→結果→誤答復習を確認する。実マイクの認識精度は自動検査済みとしない。
