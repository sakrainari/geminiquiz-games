GeoGuessr 現地文字・初見殺し解読チャート

英語のアルファベットと形が似ているのに音が違う「偽の友（False Friends）」を中心に覚えよう！

1. キリル文字（ロシア・ウクライナ・ブルガリア等）
  • В в = V (ヴ) ※Bではない！（Б б が B）
  • Н н = N (ヌ) ※Hではない！（Х х が H/Kh）
  • Р р = R (ル) ※Pではない！（П п が P）
  • С с = S (ス) ※Kではない！
  • У у = U (ウ) / Г г = G (グ)
  • Д д = D (ド) / Л л = L (ル)
  • Ж ж = Zh (ジュ) / Ш ш = Sh (シュ)
  • Я я = Ya (ヤ) / Ю ю = Yu (ユ)
2. ギリシャ文字＆東欧特殊ラテン文字
  • Θ θ = Th (ス/テ) / Δ δ = D (ズ/デ)
  • Π π = P (プ) / Ρ ρ = R (ル) / Σ σ = S (ス)
  • Μπ = B (ブ) / Ντ = D (ド) ※ギリシャ特有の合字
  • Ł ł (ポーランド) = W (ウ/ヴ) ※Lではない！
  • W w (ポーランド) = V (ヴ/フ) / Ó ó = U (ウ)
  • C c (東欧全般) = Ts (ツ) / Č č, Ć ć = Ch (チ)
  • Š š, Ş ş, Ś ś = Sh (シュ) / Ž ž = Zh (ジュ)
3. 韓国ハングル（母音と頭子音の組み合わせ）
  • ㄱ=K/G, ㄴ=N, ㄷ=T/D, ㄹ=R/L, ㅁ=M
  • ㅂ=P/B, ㅅ=S, ㅇ=無音/ng, ㅈ=Ch/J, ㅎ=H
  • ㅏ=a, ㅓ=eo(オ), ㅗ=o, ㅜ=u, ㅣ=i
  • 頻出接尾辞：시(市=シ) / 도(道=ド) / 군(郡=グン)
4. アラビア文字・タイ文字の攻略コツ
  • アラビア文字は右から左へ読む！
  • ا = A(長母音), و = W/U/O, ي = Y/I, ت = T, د = D, س = S, م = M, ن = N
  • タイ文字の州・都市マーカー：เชียง (チェン), นคร (ナコーン=都市), บุรี (ブリー=街)
