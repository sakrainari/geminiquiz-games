# 🎮 GEMINI QUIZ ARCADE

**[ゲーム一覧から遊ぶ](https://sakrainari.github.io/geminiquiz-games/)**

登録不要のブラウザ用クイズ集です。内蔵問題はAPIキーなしで遊べます。

| ゲーム | 収録内容 |
| --- | --- |
| [音声早押しクイズ](https://sakrainari.github.io/geminiquiz-games/voice_answer_quiz.html) | 世界遺産・世界の地理・一般教養・海外地名の4カテゴリ各25問、計100問 |
| [GEO地名でGO!](https://sakrainari.github.io/geminiquiz-games/geo_go.html) | タイ・キリル・ギリシャ・東欧・ハングル・アラビアなど、重複を除いて57都市 |
| [タイ県名ショートシアター](https://sakrainari.github.io/geminiquiz-games/thai_short_player.html) | タイ地名の構成をブラウザ標準音声と字幕で学習 |

## 遊び方

1. ゲーム一覧からゲームを選びます。
2. 音声早押しでは、出題スタイル・制限時間・出題数（5 / 8 / 20 / 全問）を選び、カテゴリまたは全カテゴリ混合を開始します。
3. 早押しボタン（Space / Enterも可）を押し、声または文字入力で答えます。マイクを使わない場合は「自動マイク」をOFFにしてください。
4. 正誤と解説を見て次の問題へ進みます。結果画面から間違えた問題だけを復習できます。

同じカテゴリでは、ページを開いている間は未出題の問題を優先します。カテゴリ混合の出題履歴はカテゴリ別とは独立です。リロードすると履歴はリセットされます。

地名道場は、日本語の読み・登録された別解を声や文字で回答するゲームです。解説に文字の分解を掲載しています。マイクをOFFにしても制限時間と文字入力は続きます。コース間で同じ都市が出ることがありますが、総合サバイバル10問では都市の重複を除いて選びます。標識は学習用の模式図で、実際の道路の距離・案内を再現するものではありません。

## 音声について

- PC / AndroidのChrome、Edgeを推奨します。音声認識の可否はブラウザやOS、ネットワークに依存します。
- 音声回答にはマイクの許可が必要です。公開版はHTTPSです。非対応・権限拒否時も文字入力で遊べます。
- 読み上げは端末の日本語音声を使います。特定のキャラクター音声は含みません。
- ひらがな・カタカナ・全角半角・一般的な前置きや語尾を吸収します。別解リストにある名称全体で判定します。
- 実マイクの認識精度は、利用する端末で確認してください。

## Geminiによる問題生成（任意）

AI生成を利用する場合だけ、ご自身のGemini APIキーと利用可能なモデルIDを入力します。キーをソースに埋め込む必要はなく、ブラウザのストレージにも保存しません。画面を開いている間だけ入力欄に保持され、生成時にGoogleのAPIへ送信されます。利用枠によって料金が発生する場合があります。

モデルID・APIキー・利用制限はGoogle側の設定に従います。出力はデータ形式を検査しますが、内容の正確性は保証しません。実キーを使う通信の動作確認は行っていません。内蔵100問はこの設定に関係なく遊べます。

- [Google Gemini API generateContentリファレンス](https://ai.google.dev/api/generate-content)
- [Google Gemini API 構造化出力](https://ai.google.dev/gemini-api/docs/structured-output)

## ローカル起動・開発

リポジトリ全体をダウンロードして `index.html` を開くか、HTTPサーバーで配信します。追加問題と共通処理は外部JSなので、HTMLだけを取り出さずフォルダ全体を保ってください。

```sh
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
node --test tests/quiz.test.cjs
```

ゲームにビルドやnpm installは不要です。CSS・アイコン・フォントは外部CDNを利用するため、完全オフライン動作には対応していません。GitHub Pagesは `main` ブランチのルートを公開します。

## 問題の追加

`question-bank.js` に追加問題と都市データがあります。既存問題は各HTML内にあります。各問題には正解・読みなどの別解・ヒント・解説を付け、重複と表記を確認してから上の検査コマンドを実行してください。収録数を変更した際は、画面・README・検査の期待値も更新します。

世界遺産の確認には [UNESCO世界遺産一覧](https://whc.unesco.org/en/list/) を参照しています。サグラダ・ファミリアの登録対象は地下聖堂と生誕のファサードです（[ガウディの作品群](https://whc.unesco.org/en/list/320/)）。自主制作の学習用問題で、検定の公式問題・出題範囲保証ではありません。

`archive/` は旧試作、`docs/` は当初の仕様メモです。現行版の機能は本READMEと実画面を参照してください。
