# 🎮 GEMINI QUIZ ARCADE

**[ゲーム一覧から遊ぶ](https://sakrainari.github.io/geminiquiz-games/)**

登録不要のブラウザ用クイズ集です。内蔵問題はAPIキーなしで遊べます。

## NEW：Codex版・音声早押しクイズ

**[Codex版を遊ぶ](https://sakrainari.github.io/geminiquiz-games/codex/)**

アーケード音声早押しクイズを別ページに作り直した版です。4カテゴリ100問、混合出題、5 / 10 / 20 / 全問のラウンドに対応しています。

- 早押しでマイクを自動起動。回答中は連続認識し、無音で切断されたときも再接続します。文字回答は常時使えます。音声を使わない場合は右上の設定で自動マイクをOFFにしてください。
- 不一致の発話では採点せず、言い直しを続けられます。未確定の認識は表示だけに使い、確定した正解で採点します。
- 回答時間は8秒・12秒・20秒・制限なし。発話中は最大6秒延長します。ゆっくり音声で遊ぶ場合は「制限なし」を選んでください。
- 正解・パス・一時停止・終了時にはマイクを停止します。権限拒否で再接続を繰り返さず、音声のエラー理由を表示します。
- タブを離れると一時停止します。早押しはSpace、解説から次へはEnter。日本語変換中はショートカットを無効にします。
- 結果画面から誤答だけを復習できます。苦手問題のIDのみ端末に保存します。認識違いの自己申告は得点・自動採点の正解数とは分けて表示します。
- Codex版は外部CDN・APIキー不要です。マイクの認識にはブラウザ側の音声サービスやネットワークが必要な場合があります。端末やブラウザによる認識精度は保証できません。

実装は `codex/`、仕様は `docs/codex-version.md` にあります。問題を既存データから更新する場合は `node scripts/build-codex-data.cjs` を実行します。検査は `node --test tests/*.test.cjs` です。

音声処理の仕様：[連続認識](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/continuous)、[認識終了イベント](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/end_event)。自動検査ではイベントを再現しています。実マイク・各端末の認識精度は別途確認してください。

### マイクが反応しない場合

**[マイク確認画面](https://sakrainari.github.io/geminiquiz-games/codex/microphone.html)** で、①入力音量、②音声から文字への変換を個別にテストできます。音量テストは端末内で処理し、音声を録音・保存・送信しません。文字変換テストはブラウザの音声認識サービスを利用します。

- 音量メーターが動かない場合：表示されたマイク名、Chromeの既定マイク、機器のミュート、Windowsの入力音量を確認します。
- 音量メーターは動くが文字が出ない場合：文字変換側の「認識開始・マイク入力・発話検知・文字受信」とエラーコードを確認します。この結果だけで原因を断定しません。
- ゲームでも接続待ち・マイク入力開始・発話検知を区別して表示します。認識開始後8秒間文字が届かない場合は確認画面を案内します。

テストは手動停止でき、音量は15秒・文字変換は20秒で終了します。タブを離れた場合もマイクを解放します。ブラウザやOSの設定は自動変更しません。

## 遊び方

1. ゲーム一覧からゲームを選びます。
2. 音声早押しでは、出題スタイル・制限時間・出題数（5 / 8 / 20 / 全問）を選び、カテゴリまたは全カテゴリ混合を開始します。
3. 早押しボタン（Space / Enterも可）を押し、声または文字入力で答えます。マイクを使わない場合は「自動マイク」をOFFにしてください。
4. 正誤と解説を見て次の問題へ進みます。結果画面から間違えた問題だけを復習できます。

同じカテゴリでは、ページを開いている間は未出題の問題を優先します。カテゴリ混合の出題履歴はカテゴリ別とは独立です。リロードすると履歴はリセットされます。

地名道場は、日本語の読み・登録された別解を声や文字で回答するゲームです。解説に文字の分解を掲載しています。マイクをOFFにしても制限時間と文字入力は続きます。コース間で同じ都市が出ることがありますが、総合サバイバル10問では都市の重複を除いて選びます。標識は学習用の模式図で、実際の道路の距離・案内を再現するものではありません。

## 音声について

- PC / AndroidのChrome、Edgeを推奨します。音声認識の可否はブラウザやOS、ネットワークに依存します。
- 音声回答にはマイクの許可が必要です。公開版はHTTPSです。非対応・権限拒否時も文字入力で遊べます。
- 読み上げは端末の日本語音声を使います。特定のキャラクター音声は含みません。
- ひらがな・カタカナ・全角半角・一般的な前置きや語尾を吸収します。別解リストにある名称全体で判定します。
- 実マイクの認識精度は、利用する端末で確認してください。

### CODEX版の読み判定

`codex/` では、通常の正解・別解との文字照合に加えて、漢字交じりの回答を
カタカナの読みにそろえて照合します。例えば「ストーン返事」は
「ストーンヘンジ」、「万里の頂上」は「バンリノチョウジョウ」として、
正解や登録された別解の読み全体と一致した場合に正解になります。
部分一致や一音違いのあいまい判定は追加していません。長音を含む従来の
正規化ルールは今回変更していません。

音声認識の確定結果と文字入力の両方に適用します。音声の途中結果は表示だけで、
採点しません。回答中は認識した原文と判定用の読みを表示し、読みだけで
一致した正解にはその旨を表示します。補助辞書は各問題の `aliases` です。
辞書が扱えない漢字や固有名詞は読みの照合ができない場合があります。

読みへの変換には [Kuromoji.js](https://github.com/takuyaa/kuromoji.js) と
同梱辞書を使います。初回は約22 MBの圧縮辞書を同じサイトから読み込み、
ホームに準備状態を表示します。変換処理自体はブラウザ内で動き、別の
外部サービスへ回答文を送りません。音声から文字への認識は従来どおり
ブラウザの認識サービスを使います。辞書準備中・取得失敗時も従来の文字判定を
利用でき、再読み込みで辞書の準備をやり直せます。

同梱物の出典とライセンスは `codex/vendor/kuromoji/` にあります。
読み判定の変更時は、実際の同梱辞書を使う検査も実行してください。

```sh
node --test tests/codex.test.cjs tests/codex-voice.test.cjs tests/codex-reading.test.cjs tests/microphone.test.cjs tests/quiz.test.cjs
```

## Geminiによる問題生成（任意）

AI生成を利用する場合だけ、ご自身のGemini APIキーと利用可能なモデルIDを入力します。キーをソースに埋め込む必要はなく、ブラウザのストレージにも保存しません。画面を開いている間だけ入力欄に保持され、生成時にGoogleのAPIへ送信されます。利用枠によって料金が発生する場合があります。

モデルID・APIキー・利用制限はGoogle側の設定に従います。出力はデータ形式を検査しますが、内容の正確性は保証しません。実キーを使う通信の動作確認は行っていません。内蔵100問はこの設定に関係なく遊べます。

- [Google Gemini API generateContentリファレンス](https://ai.google.dev/api/generate-content)
- [Google Gemini API 構造化出力](https://ai.google.dev/gemini-api/docs/structured-output)

## ローカル起動・開発

リポジトリ全体をダウンロードして `index.html` を開くか、HTTPサーバーで配信します。追加問題と共通処理は外部JSなので、HTMLだけを取り出さずフォルダ全体を保ってください。

```sh
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
node --test tests/quiz.test.cjs
```

ゲームにビルドやnpm installは不要です。CSS・アイコン・フォントは外部CDNを利用するため、完全オフライン動作には対応していません。GitHub Pagesは `main` ブランチのルートを公開します。

## 問題の追加

`question-bank.js` に追加問題と都市データがあります。既存問題は各HTML内にあります。各問題には正解・読みなどの別解・ヒント・解説を付け、重複と表記を確認してから上の検査コマンドを実行してください。収録数を変更した際は、画面・README・検査の期待値も更新します。

世界遺産の確認には [UNESCO世界遺産一覧](https://whc.unesco.org/en/list/) を参照しています。サグラダ・ファミリアの登録対象は地下聖堂と生誕のファサードです（[ガウディの作品群](https://whc.unesco.org/en/list/320/)）。自主制作の学習用問題で、検定の公式問題・出題範囲保証ではありません。

`archive/` は旧試作、`docs/` は当初の仕様メモです。現行版の機能は本READMEと実画面を参照してください。
